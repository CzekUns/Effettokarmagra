# Effetto Karmagra

Arcade maze-chase 2D per browser, ispirato al concept **Il giovane Biaggio Gelo**.

Gioco originale top-down: palline bianche da raccogliere, pillole di trasformazione, personaggio con cappellino rosso e occhiali, avversarie con gonne lunghe (corte durante il potenziamento).

Giocabile su computer (tastiera) e telefono (controlli touch). Nessun backend richiesto. Hosting previsto su GitHub Pages.

Avvio: aprire `index.html` nel browser o pubblicare la branch `main` dalla root in Settings → Pages.

Asset vettoriali originali in `assets/characters/`.
